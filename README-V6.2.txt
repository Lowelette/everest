Everest CMS v6.2 — clean product details

Что изменено:
- публичное окно «Подробнее» теперь центрировано и не прилипает к левому верхнему углу;
- на desktop фото остаётся слева, справа прокручивается только информация;
- характеристики и параметры каталога показываются полностью;
- действия «Бесплатный замер / MAX / WhatsApp» остаются внизу информационной части;
- в CMS обычный клик по карточке открывает аккуратный предпросмотр модели;
- ссылка «Открыть страницу» удалена с каждой карточки;
- блок «Дополнительные настройки» и выбор вида заглушки удалены из формы;
- для дверей без фото используется стандартная заглушка автоматически;
- заголовок существующей модели: «Редактирование модели»;
- исправлена обработка старых характеристик, где \\n мог сохраниться буквальным текстом.

SQL не требуется.
После распаковки patch поверх текущего проекта: npm run deploy
Для GitHub Pages отдельно заменить css/catalog.css и js/catalog-runtime.js.
