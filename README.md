# Сайт «Эверест» — версия 8

## Структура

- `index.html` — главная страница;
- `catalog-entrance.html` — каталог направлений входных дверей;
- `catalog-interior.html` — каталог направлений межкомнатных дверей;
- `css/styles.css` — общие стили сайта;
- `css/catalog.css` — стили двух каталогов;
- `css/themes.css` — исходная тема, десять демонстрационных палитр и панель выбора;
- `js/app.js` — анимации, квиз и формы;
- `js/themes.js` — переключение палитр, сохранение выбора и ссылки на конкретную тему;
- `assets/images/` — будущие фотографии дверей;
- `assets/icons/` — будущие отдельные иконки.

## Что уже работает

- переходы с главной на два отдельных каталога;
- адаптивная мобильная версия;
- короткий подбор из трёх вопросов;
- заявки через WhatsApp;
- отдельные CTA для каждой категории дверей;
- временный переключатель: Original + 10 палитр на всех страницах;
- сохранение выбранной палитры при переходах и перезагрузке;
- копирование ссылки на конкретный цветовой вариант.
